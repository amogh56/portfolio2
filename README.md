## 🚀 Quick Setup & Deployment

### 1. Configure Contact Form Notifications
To receive email notifications when a visitor submits the contact form:
1. Obtain a free Access Key at [web3forms.com](https://web3forms.com) using your email (`amoghyalameli26@gmail.com`).
2. Open `index.html` and replace `"YOUR_ACCESS_KEY_HERE"` with your access key in the script:
   ```javascript
   const WEB3FORMS_ACCESS_KEY = "your-actual-access-key";
   ```

### 2. View Locally
Open `index.html` directly in any web browser, or serve it with any static server:
```bash
npx serve .
```

### 3. Deploy to GitHub Pages
1. In your GitHub repository (`amogh56/portfolio2`), go to **Settings** > **Pages**.
2. Under **Build and deployment** > **Branch**, select `main` and `/ (root)`.
3. Click **Save**. Your site will be live at `https://amogh56.github.io/portfolio2/` in moments!
